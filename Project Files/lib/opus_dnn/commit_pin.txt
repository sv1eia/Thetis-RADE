build_outstanding:
  Opus at this commit ships CMake only (no MSVC win32/*.vcxproj).
  Three viable paths to produce libopus.lib for the Thetis MSVC v145 build:

  (a) Run CMake on Windows host once, ingest the generated opus.vcxproj into
      Thetis_VS2026.sln. Requires `winget install Kitware.CMake` first.

  (b) Author build/opus_dnn.vcxproj from scratch listing the files in:
        celt_sources.mk        + CELT_SOURCES from cmake/OpusSources.cmake
        silk_sources.mk        + SILK_SOURCES (float ones for Opus encoder/decoder)
        opus_sources.mk        + OPUS_SOURCES
        lpcnet_sources.mk      + DEEP_PLC_SOURCES + DRED_SOURCES + OSCE_SOURCES
        + dnn/x86/x86_dnn_map.c, dnn/x86/nnet_avx2.c, dnn/x86/nnet_sse4_1.c, dnn/x86/nnet_sse2.c
      Compile defines: ENABLE_DEEP_PLC ENABLE_DRED ENABLE_OSCE OPUS_BUILD HAVE_LRINT HAVE_LRINTF
      Include paths:   include/, celt/, silk/, silk/float/, dnn/, .

  (c) Cross-compile from WSL with mingw-llvm (FreeDV-GUI does this via
      cmake-windows.yml). Commit resulting libopus.a/lib as a vendored prebuilt.
      Trades reproducibility for setup simplicity.

  Decision deferred to a follow-up step in the implementation.
