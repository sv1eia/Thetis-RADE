FreeDV-GUI rade_text.c LDPC reliable-text codec, vendored slice
================================================================

Purpose
-------
Decode the EOO (end-of-over) callsign frame using the SAME wire format
that FreeDV-GUI 2.3.0 stations transmit.  Replaces the simple 7-bit-MSB
codec built into radae_c (rade_rx_get_eoo_callsign /
rade_tx_set_eoo_callsign) which is *not* the FreeDV-GUI on-air format.

Wire format
-----------
8-byte payload  =  1-byte CRC8 (poly 0x1D)  +  7 chars * 6 bits = 48 bits
                                            (custom 6-bit charset:
                                             '0'-'9'->10-19, 'A'-'Z'->20-46,
                                             ' '->47, ASCII 38-47->1-9)
                                            zero-padded to 56 information bits
LDPC encode     =  56 -> 112 coded bits using "HRA_56_56" code
Interleave      =  Gray-coded interleaver (gp_interleaver)
Modulation      =  56 QPSK symbols (= 112 floats, IQ pairs)
Wire delivery   =  rade_tx_set_eoo_bits / rade_rx returns soft floats
