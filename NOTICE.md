# Thetis-RADE — Contributors

This is a fork of [ramdor/Thetis](https://github.com/ramdor/Thetis), itself a
fork of OpenHPSDR's PowerSDR, now having RADE V1 digital-voice and a native
FreeDV Reporter client added on top.
